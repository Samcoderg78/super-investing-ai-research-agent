# Super Investing — AI Innovator Intern Assignment

A small source-grounded research-brief generator for the **fictional** Sarvottam Cables Ltd (NSE: SRVCABLE) case pack. It loads Markdown documents, excludes a known entity mismatch, detects conflicting Q1 revenue figures, and generates a brief with traceable source IDs.

## Features

- **Python, standard library only** for local execution; no `pip install` required.
- Optional Gemini API generation (default model: `gemini-2.5-flash`). A free-tier quota may be available depending on Google's current terms, region, and account. Check AI Studio for current model access and limits; no paid call is required to test the offline mode.
- Evidence bundle includes source, URL, publication date, document type, and raw text.
- Prompt-injection defence: document text is treated as untrusted evidence, not instructions.
- Entity resolution rule excludes the unrelated Sarvottam Cable Network local cable-TV operator.
- Revenue discrepancy detection highlights the official filing's ₹1,248 crore vs Business Daily's ₹1,428 crore.
- LLM output is checked for required sections, valid source IDs, disclosure of known conflict, and promotional stock-tip language. If `--provider auto` cannot get valid model output, it falls back to the deterministic generator and prints a warning.

## Run locally

Python 3.10+ is recommended.

```bash
python agent.py --ticker SRVCABLE --provider offline
```

Output is written to `outputs/final_brief.md` by default. To choose another path:

```bash
python agent.py --ticker SRVCABLE --provider offline --output outputs/my_brief.md
```

### Enable Gemini (optional)

1. Get an API key through Google AI Studio and verify current free-tier availability/limits.
2. Set the key as an environment variable. Do not commit the key to GitHub.

PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_KEY_HERE"
$env:GEMINI_MODEL="your_model_name"
python agent.py --ticker SRVCABLE --provider gemini
```

macOS/Linux:

```bash
export GEMINI_API_KEY="YOUR_KEY_HERE"
export GEMINI_MODEL="your_model_name"
python agent.py --ticker SRVCABLE --provider gemini
```

`--provider auto` uses Gemini if `GEMINI_API_KEY` is set; otherwise it uses the offline generator. `--provider gemini` fails clearly if the key/API call is unavailable, rather than silently pretending the model ran.

## Project files

- `agent.py` — document loading, filtering, conflict detection, Gemini call, output validation, and offline fallback.
- `system_prompt.md` — separate system prompt.
- `research_pack/` — all eight provided documents.
- `outputs/final_brief.md` — brief generated by the offline generator for the provided pack.
- `tests/test_agent.py` — lightweight regression tests.
- `test_log.md` — three design iterations and observed results. It clearly distinguishes local offline tests from any real API execution.
- `demo_script.md` — suggested 2–3 minute recording script.

## Design choices and limitations

1. **Source-first over free-form browsing:** the assignment explicitly says not to search for this fictional company online. Only the provided pack is used.
2. **Conflicts are surfaced, not resolved by guesswork:** official filing is labelled the primary reference, but the revenue discrepancy remains open.
3. **Prompt injection and source trust:** the blog's hidden instruction is ignored; its promotional claims are not used as evidence for a recommendation.
4. **Entity mismatch:** the local cable-TV operator is excluded because its business and identity do not match the listed manufacturer.
5. **No financial advice:** the brief does not give a buy/sell rating.

Limitations: conflict detection is deliberately narrow and rule-based for this assignment; it is not a general financial fact-checker. LLM citation validation checks source IDs and required disclosures, not whether every individual number is semantically entailed by its cited text. API availability, pricing, quotas, and model names can change. The fictional pack is not suitable for real investment decisions.

